# tennis_serve_aim 变更记录

## 0.7.0 — 2026-09-21

- 功能/接口：机器人当前位置的发球目标朝向规划。当前代码按层级归档，本次补齐包 wiki。
- 算法和配置：直接使用请求中的定位快照与场地目标，计算目标向量的 yaw；不规划发球路径。
- 测试结果：`test/test_aim.py` 验证位置到朝向的纯函数；现场底盘到位未验证。
- 已知限制：请求不含定位时间戳；新鲜度由 launcher planner 检查。异常目标返回 `PLAN_REJECTED`。
- Git commit/tag：本地初始化提交后记录；沿用现有包版本，未创建发布标签。
