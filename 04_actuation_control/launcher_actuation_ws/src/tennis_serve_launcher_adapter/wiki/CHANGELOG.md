# tennis_serve_launcher_adapter 变更记录

## 未发布 — 命令俯仰模式

- 硬件没有实际俯仰角反馈时，收到有效 setpoint 后直接采用命令俯仰角；发球门禁不再等待或校验俯仰反馈。
- 轮速反馈、轮速方向校验、目标有效期和拨球反馈逻辑保持不变。
- 验证：`test_adapter_core.py` 通过；实球发射未验证。

## 1.3.0 — 2026-09-21

- 功能/接口：发球机构 ROS 指令到现有底层硬件话题的适配。当前代码按层级归档，本次补齐包 wiki。
- 算法和配置：校验 setpoint 时效和 job/shot 一致性，映射上下轮方向、限幅与俯仰；只接受唯一拨球命令；汇总真实硬件反馈。
- 测试结果：Adapter 现有测试覆盖目标映射和反馈；真实 F407 协议由现有底层负责，现场联调未验证。
- 已知限制：俯仰角仅为命令估算值，不是硬件实测值；轮速限幅 7857 rpm；硬件状态超时 1 s，拨球结果超时 8 s。
- Git commit/tag：本地初始化提交后记录；沿用现有包版本，未创建发布标签。
