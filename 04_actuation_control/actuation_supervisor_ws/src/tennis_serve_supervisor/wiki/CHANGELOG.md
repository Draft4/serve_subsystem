# tennis_serve_supervisor 变更记录

## 0.7.0 — 2026-09-21

- 功能/接口：单球执行动作、安全门禁与拨球许可。当前代码按层级归档，本次补齐包 wiki。
- 算法和配置：Action 执行中检查定位、朝向、速度、轮速、俯仰、位置偏移、急停与反馈；持续刷新 setpoint；每球只发布一次唯一 FeedCommand。
- 测试结果：`test_contract_files.py` 静态检查部分契约；底盘订阅者、实机急停和拨球反馈需现场验证。
- 已知限制：拨球前门禁须持续稳定默认 0.2 s；位置偏移超过 0.5 m 持续 0.5 s 后中止；feedback 模式等待拨球结果默认 8.5 s。
- Git commit/tag：本地初始化提交后记录；沿用现有包版本，未创建发布标签。
