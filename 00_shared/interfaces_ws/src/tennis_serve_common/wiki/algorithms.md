# 实现、参数和验证

`core.py` 把定位转换到 `court_origin_v2`，对绝对目标做边界校验，计算目标 yaw 与角度归一化。

## 参数与假设

默认运行参数以 `config/*.yaml`、launch 文件和源码中 `declare_parameter`
为准。场地坐标统一为 `court_origin_v2`：本方底线左角为原点，X 向右，Y 朝球网；
yaw 为 0 时朝 +Y，逆时针为正。模型内部旧 Y 坐标只在模型边界转换一次。

## 限制与失败行为

只负责几何与数值校验；定位新鲜度及机器人是否停止由调用方检查。

## 验证

`test/test_aim.py` 间接覆盖朝向几何；当前包无独立测试目录。
